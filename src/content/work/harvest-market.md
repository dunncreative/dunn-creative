Harvest Market's private-label range had grown organically to more than sixty
products — and it looked like it. Each package had been designed in isolation, so
the shelf read as a jumble of unrelated brands instead of one confident house
line. New launches meant starting from scratch every time.

We designed a packaging system rather than a set of packages: a consistent
architecture for naming, color-coded categories, a flexible label grid, and clear
rules that hold from pantry staples to seasonal specials. The same logic extends
to in-store signage and merch, so the brand feels coherent everywhere a shopper
meets it.

The result is a shelf that finally looks intentional and a system the team can
extend themselves. Adding a new SKU is now a matter of dropping content into the
template — fast, consistent, and unmistakably Harvest.
